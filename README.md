# Japan Electronics - Premium Landing Website

A modern, high-converting single-page landing website for **Japan Electronics**, a consumer electronics business in Pakistan. Built with an Apple & Sony inspired aesthetic, pristine clean white background, electric blue accents, responsive glassmorphism, Framer Motion animations, and direct conversion hooks.

## ✨ Features & Architecture

- **Sticky Floating Glass Navbar**: Smooth glassmorphism with backdrop blur, scroll shadow transition, mobile drawer navigation, and direct call action.
- **Interactive Hero Section**: High-resolution multi-layered product composition (Smart TV, Laptop, Smartphone, Headphones, Smartwatch) with depth and smooth floating keyframe animations.
- **Trust & Stats Strip**: Highlighting Quality Products, Trusted Service, Modern Technology, and Easy Ordering.
- **Infinite Marquee Ticker**: Continuous horizontal ticker (`SMART TV • LAPTOPS • AUDIO • SMARTPHONES • SMART DEVICES`).
- **Featured Products Grid**: Category tabs filtering (TVs, Audio, Laptops, Phones, Smart Devices), hover image zoom, detail modals with full specs, direct phone call, and instant WhatsApp inquiry links.
- **Categories Showcase**: Visual grid of 6 main electronics categories with background images and hover scale transitions.
- **Editorial Product Showcase**: Split section featuring flagship Smart Technology narrative.
- **Why Choose Japan Electronics**: 4 feature cards with line icons and scroll reveal effects.
- **About Us**: Narrative with animated rotating trust badge (`Quality • Technology • Trust`).
- **Dark Premium CTA Section**: High-contrast dark charcoal section driving immediate call conversions.
- **Contact Form**: Direct contact cards + validated input form (Name, Phone Number, Product Interest, Message) with feedback state.
- **Floating WhatsApp Button**: Pulse aura effect fixed at bottom-right linking directly to WhatsApp.
- **SEO & LocalBusiness Schema**: Schema.org JSON-LD, Open Graph tags, semantic HTML tags, and optimized asset loading.

## 🛠️ Tech Stack

- **Framework**: React 18 (Vite)
- **Styling**: Tailwind CSS v3 + Vanilla CSS Utility Tokens
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Design Inspiration**: Apple, Sony, Samsung, Premium Japanese Electronics Showrooms
